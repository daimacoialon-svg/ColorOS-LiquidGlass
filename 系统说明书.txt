ColorOS-LiquidGlass V1.9.205.227｜自适应曲面轮廓实验版

稳定基线：V1.9.205.225/V226 的正式二维曲面位移、5/9 点局部采样与图标光学绘制保持不变。

本版在 GlassLens191 的 V221 正式 Shader 内增加单次渲染的曲面轮廓光学分量：按曲面法线、边缘深度和光照方向计算薄层轮廓与向内衰减的透射高光。不会叠加第二个 Canvas 描边层。原有 edgeStrength 参数仍控制轮廓总强度；如果原有边缘高光开关关闭，新轮廓也关闭。

安全回退（Termux）：
  su -c settings put global liquidglass_contour_227 0
恢复新轮廓：
  su -c settings put global liquidglass_contour_227 1
以上开关在 Shader 每次绘制时读取，便于现场对比。V219 Shader 回退时新轮廓自动不生效。

测试：在相同壁纸、同一位置、折射 0%/50%/100% 分别拍照，观察纯色区域轮廓与高对比水平线阶梯；再关闭新轮廓复拍以隔离效果。

重要：本版没有声称彻底修复高强度采样阶梯；二维位移函数未更改，以保护稳定视觉基线。没有新增 UI 或 Root 快照字段，新增项是独立的 Settings.Global 实验开关，旧 UI 参数映射不变。

编译：请使用项目内 GitHub Actions；当前环境未完成 Android Gradle 编译与真机测试。
