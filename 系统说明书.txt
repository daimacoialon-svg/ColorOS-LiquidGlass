ColorOS-LiquidGlass V1.9.205.221｜图标薄内缘光学与二维曲面局部抗锯齿

一、适用环境
- 一加 13T，ColorOS 15 / Android 15，KernelSU，LSPosed Vector。
- Android Studio 工程，JDK 17，Android SDK 35；GitHub Actions workflow 构建 debug APK。
- V1.9.205.219 的二维曲面折射与强度滑块已在用户真机确认恢复。此版在 V220 上修订；新光学视觉尚需真机验证。

二、本版改动
1. 桌面应用图标薄内缘明暗光学
   - 删除 V220 的外部 BlurMaskFilter 光晕/模糊描边（避免月晕）。
   - 从图标真实透明度轮廓或自适应图标遮罩获取内缘距离场，图标外部无任何模块发光像素。
   - 在图标内部约 5.8% 边长的最大光影范围，使用高斯连续衰减；内核主要集中在边缘数像素。
   - 左上与右下圆角有柔和内向亮部；右上与左下圆角有更浅的内向暗部；直边保留微弱内缘亮线。
   - 采用按图标 View / Drawable / 尺寸缓存的离屏位图，不每帧重新计算轮廓距离场；不改变图标点击区域。
   - 配置沿用 icon_optics_204，不新增未同步的设置键，原开关状态保持不变。

2. 二维曲面透镜图形平滑
   - 正常模式优先尝试 V221 的独立 RuntimeShader；新增内区平滑距离场以降低圆角/长边交界的法线脊线。
   - 角部折射位移做平缓、小幅的局部衰减，避免单靠压低 outline/shadow 试图掩盖采样折痕。
   - 按像素风险分配采样：普通区域 1 点；高风险区域 5 点；底部中心高对比纹理与角区极高风险时可达 9 点。
   - 每一个样本点重新评估各自的透镜位移和有效采样范围（真实亚像素采样，而非重复读取同一个坐标）。
   - 1→5 和 5→9 之间用 smoothstep 权重连续混合，避免采样区域本身形成一条突变线。
   - 不提供“全屏强制九点”，以减少多容器与桌面滑动时的 GPU 负担；实际性能仍需真机观察。

3. 稳定性与参数一致性
   - 保留 V219 已确认的文件夹/Dock 单路绘制、UI→Launcher 实时通知、33 项开机快照与 0.1dp 模糊精度。
   - 如果 V221 Shader 创建失败，会先尝试已验证的 V219 生产 Shader；两者都失败才由绘制层回退到普通壁纸采样。
   - 旧诊断 Shader 和老绘制模式仍只允许显式调试开关进入；V219 的旧诊断清理逻辑保持有效。
   - 不重设原有的模糊、底色、Dock 或透镜强度参数；保持现有渲染选项和开关。

三、编译与安装
1. 用 Android Studio 打开解压后的 ColorOS-LiquidGlass-V1.9.205.221 顶层项目文件夹。
2. 使用 JDK 17，Android SDK 35，构建 :app:assembleDebug；也可将源码提交到 main 由 .github/workflows/build-apk.yml 生成 debug APK。
3. 安装新 APK，确认 LSPosed Vector 的 ColorOS Launcher 作用域仍启用，重启 Launcher 或手机。
4. 本版没有修改 Root 辅助脚本配置结构，不需清除 SharedPreferences，也不必清空原有用户参数。

四、建议真机测试
- 先以 V220 相同壁纸、相同二维曲面强度作对照，重点比较底部中间黑白压缩层带和四角斜向短线。
- 在 0%、50%、100% 强度下验证透镜立即响应；分别测试小/大正方文件夹、长条文件夹、Dock。
- 检查天气图标的内缘：没有外部月晕，左上/右下适度提亮，右上/左下浅暗，中心不泛白。
- 左右滑动桌面尤其是靠近右边缘时，注意是否出现新的采样拉伸、闪烁、发热或掉帧。
- V221 是实验修正版，不表示阶梯和角区斜线已经通过真机验收；如出现异常，保留 V219 已确认可用的安装包便于回退。

五、日志与排障
Termux：
su -c 'logcat -d -v time | grep -E "LiquidGlass221|LENS_SHADER_221_FAILED|LENS_SHADER_CREATED|ICON_INNER_221|CLEAN_LENS_219|CONFIG_APPLIED_203|BOOT_SNAPSHOT_REJECT" | tail -120'

- LENS_SHADER_CREATED production=221 adaptiveSSAA=true：V221 Shader 已创建（不代表视觉无瑕疵）。
- LENS_SHADER_221_FAILED fallback=219：V221 Shader 创建失败，尝试 V219 生产 Shader。
- LENS_SHADER_CREATED production=219 fallback=true：成功退回稳定 V219 Shader。
- CLEAN_LENS_219 shader=FAILED fallback=CROP：包括 V219 在内的可用生产 Shader 均无法使用，退回普通采样。
- ICON_INNER_221：图标内缘位图在 diagnostics 开启时的缓存构建日志。
- CONFIG_APPLIED_203：原有 Launcher 参数应用确认日志。
