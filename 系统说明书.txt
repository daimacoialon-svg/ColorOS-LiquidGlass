ColorOS-LiquidGlass V1.9.205.288.9｜原生采样桥接偶发失步实验修复版

在 V288.8 原生 Canvas + Kyant 融合模式基础上：
1. 保留原生 View Canvas 对壁纸的实时采样，Kyant Compose Backdrop 光学管线不变。
2. 原生采样通知采用 coalesced post，避免每次 native onDraw 产生无上限的通知队列。
3. Compose 实际绘制时校验原生采样坐标与当前 FolderIcon 矩阵；如果出现不一致，在当前绘制阶段通过相同原生 Canvas Bitmap 采样算法补齐，再交给 Kyant。
4. 开关 liquidglass_kyant_bridge_sync_2889：0=V288.8 原始桥接（对照）；1=同绘制阶段追帧（实验，默认）。需同时开启 liquidglass_kyant_native_bridge_2888=1。
5. 新增日志 KYANT2889_BRIDGE_SYNC、KYANT2889_NATIVE_PUBLISH、KYANT2889_FRAME_CATCHUP、KYANT2889_COMPOSE_CONSUME。
6. 保留 V286.2 Host 定位修复、V288.7 左右对照及所有原有 UI 参数；不添加额外 README 文件。

注意：该方案仅在 Compose 确实执行绘制时补齐最新坐标；如果 Compose 整帧未绘制，则不能保证消除所有视觉失步。尚未完成 Android SDK Gradle 编译或真机测试。
