ColorOS-LiquidGlass V1.9.205.219｜二维曲面透镜单路修复与图标内缘光学渐变

一、修复范围

1. 正式二维曲面透镜独立走 V219 轻量 RuntimeShader。
   旧版代码存在普通壁纸裁剪、旧 REFRACTION_AGSL、GlassLens191、
   材质描边等混杂调用；旧 Shader 创建失败可能让新版二维透镜无法进入。
   现在文件夹/Dock 在正常模式默认先运行独立的二维高度场折射，
   正式 Shader 不含历史 1～20 探针分支，避免复杂诊断程序编译失败拖累正常显示。
   当 Shader 创建失败时会记录 CLEAN_LENS_219 shader=FAILED，并仅在失败时回退普通裁剪；
   不再预先把壁纸裁剪和有效的透镜图像重叠绘制。

2. 在默认正式路径中，跳过 FolderIcon 结束阶段的第二次描边/材质绘制，
   停止安装只用于旧试验的 OEM Drawable、图层探针、模糊条件修改及冗余追踪 Hook，
   不再额外重画 GradientDrawable 的旧模块材质。
   不改 ColorOS 原生 Drawable 的形状和尺寸；仍可能存在系统自身的原生背景层，
   但模块不会在这些入口再次叠加旧光学图层。

3. 上次保存的非零旧诊断参数可能在多个入口叠加。
   首次启动设置界面时：关闭旧比较、绘制、原生 alpha/模糊试验，并以 Root 尝试清零
   37 个历史 Settings.Global 可视诊断键（保存原值到
   /data/local/tmp/liquidglass_legacy_globals_before_219.txt）。
   此操作不重置正式二维曲面强度、Dock 开关、模糊、透明度和色彩。
   需要再次清理时，在“维护与状态”中点“一键关闭所有旧版绘制和可视诊断模式”。
   开发用历史渲染器只可由 liquidglass_legacy_renderer_219=1 显式打开。
   历史采样网格 / AA 探针只有在 liquidglass_debug_opt_in_219=1 时可执行。
   请勿在日常使用时打开以上两个开发设置。

4. 参数统一检查：LG1 快照 33 个数字字段，在 UI/SharedPreferences、
   ConfigPublisher202、Root 辅助脚本、Launcher applySnapshot203 中保持顺序一致。
   新增 custom_blur_tenths_95 作为最后一列（0.1dp 精度），
   修复原先开机快照只保存整数 dp 的精度丢失问题。
   模糊强度与 2D 曲面强度独立，Root 脚本与 APK Assets 中脚本内容完全相同。
   非线性强度、边缘厚度、内区曲率、聚焦、反射比例以及
   曲面反射模式/反射强度/反射柔和度均送入正式 Shader 的真实计算。
   已退役的旧试验参数仍保留兼容字段，但不参与正式绘制。

5. 桌面应用图标：替换旧版轮廓粗描边为按真实图标形状计算的距离场。
   从边缘向内做连续高斯衰减，高光朝左上，轻微暗部朝右下；
   光影使用预生成 Bitmap 缓存，不按每帧重新算距离场，避免反复绘制。
   遇到无法读取自适应图标形状时使用圆角方形轮廓回退。
   该光学效果叠加于图标外观，不修改应用自身图标素材。

二、更新/恢复

1. 在 Android Studio 或 GitHub Actions 构建 :app:assembleDebug，安装新 APK。
2. 确保 LSPosed Vector 给“ColorOS Launcher / 桌面”开启模块作用域；
   KernelSU root 授权正常。
3. 打开设置 APP，等待首次旧诊断清理完成，再点“检查并更新 Root 辅助脚本”。
4. 建议至少重启 Launcher，更新 Root 脚本后重启手机一次，让开机配置读入 33 字段。
   更新不会强制重新打开此前手动关闭的 Dock。
5. 在绿色/网格纹理壁纸上检查文件夹、小/大正方形、长条、Dock、
   桌面滑动接近屏幕右侧时的边缘采样，以及折射 100% 时的边缘纹理拉伸。

三、日志与故障判断（Termux）

su -c 'logcat -d -v time | grep -E "CLEAN_LENS_219|LENS_SHADER_(CREATED|FAILED)|CONFIG_APPLIED_203|LEGACY_PROBES_219|BOOT_SNAPSHOT_REJECT" | tail -100'

正常：CLEAN_LENS_219 shader=191 singlePass=true
异常：CLEAN_LENS_219 shader=FAILED fallback=CROP（Shader 创建或绘制失败）
异常：CLEAN_LENS_219 source=NOT_READY fallback=TINT_ONLY（壁纸截图还未准备）
异常：BOOT_SNAPSHOT_REJECT（快照长度或内容不符合解析要求）

四、源码检查

python3 tools/audit_config_219.py

检查内容包括：33 字段顺序、默认值、Root 与 APK 内脚本一致、
0.1dp 精度字段、正常二维透镜路由、旧边缘合成隔离及 Shader 参数名匹配。
Java/Shell 语法已经进行静态检查；minSdk 已从不合理的 35 调整为 28，
避免大于 targetSdk 28 的构建错误（实际光学效果仅以 Android 15 / ColorOS 15 为目标）。
此环境不含 Android SDK/Gradle，
因此未产出经 Android 工具链验证的 APK，也未在 OnePlus 13T ColorOS15 真机上验证渲染。

五、备份、回滚与注意

- 升级前请保留 V1.9.205.218 源码与原 APK。
- 如正式 Shader 失败，会自动走普通壁纸采样，不会崩掉整个 Launcher 绘制入口；
  请提供上方日志，便于依据 AGSL 错误精准修复。
- 历史 Settings.Global 配置备份属于调试数据，包含开关原值，只有 Root 可读。
- 系统原生 Launcher 的模糊/遮罩仍属于系统行为，本版本仅隔离模块自身旧层。
- `liquidglass_legacy_renderer_219=1` 是仅供排障的回退，不应作为正常设置。
