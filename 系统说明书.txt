ColorOS-LiquidGlass V1.9.205.222｜全容器单调二维曲面与图标矢量内缘光学

适用：OnePlus 13T / ColorOS 15 / KernelSU / Vector LSPosed（桌面作用域）

【本版基线与核心改动】
1. 基于 V1.9.205.221 源码，保留 V219 已确认可用的二维透镜单路绘制与 UI→Launcher 实时参数链。
2. 新增 GlassLens222.java：整片玻璃统一采用连续的圆角自适应超椭圆（4/8 范数混合）映射。
   新位移不是底边中心、上沿或角部专用补丁，而是作用于文件夹及 Dock 的同一个采样坐标公式。
   在映射范数 n∈[0,1]、振幅 a≤1.5 下，切向伸缩 1+a(1−n)^2，径向伸缩
   1+a(1−n)(1−3n)，两者均为正；此设计约束了局部映射翻折风险。
   这不等同于真机视觉效果保证，也无法自行恢复源壁纸不存在的分辨率细节。
3. 删除 V221 正式透镜中偏重底部中心、角部的自适应九点采样特例。正式渲染默认单点，并明确开启
   BitmapShader 线性过滤。新增全容器的诊断图/九点采样实验用于区分映射问题与纹理混叠。
4. 正式 Shader 创建失败自动回退 V219 单路 Shader（不是曾经存在阶梯问题的 V221 Shader）。
5. 图标不再使用从 128×128 软件位图逐行生成的折线轮廓，也不使用 chamfer 距离法线。
   优先采用系统 AdaptiveIconDrawable 矢量 Mask，其他图标使用平滑圆角矩形轮廓。
   在同一矢量轮廓内部绘制窄带高光：左上/右下偏亮，右上/左下较暗，不绘制外部月晕。
   光学效果仅为叠加绘制，不会变形或挤压原图标像素。

【诊断方法】
在设置 → 维护与状态 → “展开全容器折射诊断（默认关闭）”中选择：
0 关闭，恢复正常透镜（也会关闭历史全局诊断开启键）
1 全容器实际采样坐标网格（使用图像采样坐标，与真实容器一致）
2 Jacobian 压缩 / 拉伸热图（红=压缩，蓝=拉伸；并非最终视觉颜色）
3 左右对照（左原始壁纸、右折射壁纸）
4 全域九点亚像素采样临时对照（计算量明显增加，不建议长期打开）
所有模式都要求 Root 授权，仅通过 Settings.Global 保存诊断编号，默认 0，不占用玻璃 33 项配置。
测试结束务必恢复模式 0；在各级强度下对比水平/竖直/45度网格及自然壁纸，注意滑动卡顿。

Termux（可选，同 UI 按钮等效）：
su -c 'settings put global liquidglass_aa_probe_208 0; settings put global liquidglass_debug_opt_in_219 1; settings put global liquidglass_lens_diagnostic_222 1'
su -c 'settings put global liquidglass_lens_diagnostic_222 2'
su -c 'settings put global liquidglass_lens_diagnostic_222 3'
su -c 'settings put global liquidglass_lens_diagnostic_222 4'
su -c 'settings put global liquidglass_lens_diagnostic_222 0; settings put global liquidglass_aa_probe_208 0; settings put global liquidglass_debug_opt_in_219 0'
修改后可返回设置并触发通知刷新；UI 按钮更方便。

【故障定位】
su -c 'logcat -d -v time | grep -E "LENS_SHADER_CREATED production=222|LENS_SHADER_222_FAILED|production=219 fallback|CLEAN_LENS_219|LENS_SOURCE_222|CONFIG_APPLIED_203|ICON_VECTOR_222" | tail -120'
- 出现 LENS_SOURCE_222 undersampled 表示壁纸截图分辨率比屏幕低，需优先排查输入质量。
- 若 production=222 创建失败则回退 V219；若回退亦失败，会记录 CLEAN_LENS_219 shader=FAILED。
- 四角短线可能还与原生 Launcher 底层像素或截屏缩放有关，不能仅凭源码宣称完全消除。

【配置与工程】
- 33项 SharedPreferences / ConfigPublisher / GlassConfigProvider / Launcher / Root 启动快照字段顺序保持不变。
- custom_blur_tenths_95 的 0.1dp 精度保留；Dock 手动关闭状态保留。
- 正式绘制旧 Shader 隔离机制延续 V219；清理旧版诊断功能仍可使用。
- 工程：Android Studio / AGP 8.x / Java 17 / Android SDK 35；通过 GitHub Actions gradle 8.9 编译。
- 说明：本环境进行了静态检查与数值几何测试，未连接 ColorOS 真机，也不保证 APK 在真机上已验证。
